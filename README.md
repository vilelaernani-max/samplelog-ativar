# samplelog-ativar

Página do link de ativação do SAMPLE LOG, publicada no GitHub Pages.

A chave de licença vem depois do `#` no link e não é enviada ao servidor. A página só mostra o cliente e a validade e abre o app instalado (`samplelog://ativar/<chave>`).

A fonte fica no repositório SAMPLE_LOG, em `native/ativar/index.html`. Copie de lá a cada mudança.
